# 00 — Overview

OpsPilot AI is an evidence-driven operations intelligence platform.

## Problem

Operational incidents generate fragmented signals. Engineers manually correlate logs, metrics, deployments, tickets and API failures.

## Solution

OpsPilot creates a unified incident workspace that correlates signals, gathers evidence, invokes AI for hypothesis generation, and routes consequential remediation through deterministic policies and human approval.

## Users

- On-call engineer
- SRE / platform engineer
- Incident commander
- Engineering manager
- Auditor

## Non-goals

- Fully autonomous production changes
- Arbitrary shell execution
- Replacing human incident ownership
- Treating LLM output as authoritative truth

## Core value

**Faster investigation + traceable reasoning + controlled automation.**
