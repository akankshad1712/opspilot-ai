# 10 — Architecture Decision Records

- **ADR-001 — FastAPI:** typed Python API boundary and OpenAPI integration.
- **ADR-002 — PostgreSQL:** transactional source of truth for relational incident state.
- **ADR-003 — Kafka:** durable asynchronous event processing and decoupling.
- **ADR-004 — Evidence-first AI:** AI outputs reference evidence instead of unsupported conclusions.
- **ADR-005 — Human approval:** consequential actions require deterministic policy checks and configured approval.
- **ADR-006 — OpenTelemetry:** common telemetry model across distributed services.
- **ADR-007 — Provider abstraction:** model providers remain replaceable through an internal gateway.
